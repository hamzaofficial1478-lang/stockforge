# Stockforge recovery and Windows setup review

Target branch: `claude/image-to-editable-pdf-0exjzg`.
Starting commit: `4f47639`.

## Changes

- Added original-recovery mode, enabled by default. The analysed design reaches
  SVG/PDF export without rewriting names, shifting typography, changing colors,
  or borrowing elements from other designs. The existing variation workflow
  remains available in Setup and through `SF_PRESERVE_ORIGINAL=0`.
- Added downloadable SVG/PDF/EPS links to Queue and Review. Recovery previews
  also appear in Review when manual work is needed.
- Added a reproducible starter-font download: 17 static faces, eight families,
  seven categories. Files and OFL licenses come from a pinned Google Fonts
  revision, with SHA-256 verification. Local fonts and manifests stay outside Git.
- Preserved approved font metadata on rescan; supported nested Windows font
  folders and name collisions; registered fonts in the current Windows session.
  Used actual font weight metadata and matched/rendered italic styles together.
- Corrected palette sampling: averaging a small image had blended thin text
  into its background. Sampling actual pixels and choosing real representative
  colors preserves the sample's original ink and thin gold rule.
- Wrote SVG and configuration text with explicit UTF-8 encoding. Windows' default
  encoding previously produced invalid or corrupted SVG text.
- Added Windows OCR discovery, an executable override, and app-local OCR support.
  SVG ingestion now uses the same renderer as export instead of requiring a
  separate native Cairo installation when Inkscape is available.
- Bounded Inkscape subprocess execution and reported launch/timeout errors.
  Sanitized model-generated page filenames and disambiguated repeated names.
- Prevented workspace downloads from serving model credentials or databases;
  blocked cross-origin mutations and sandboxed SVG documents served by the panel.
- Cleared old API keys when activating keyless models, rejected empty model-test
  replies, and routed image comparisons to the vision provider.
- Made zero-strength derivation leave the design unchanged. Missing-source
  designs now enter a failed state instead of remaining pending indefinitely.
- Let the Windows launcher use an already-working local Python environment when
  Python is absent from PATH.

## Installation on this PC

The Desktop Stockforge folder receives the font library and the app-local
Tesseract 5.4.0 executable, libraries, English recognition data, and orientation
data. Inkscape 1.4.4 was already installed. The system OCR installer was canceled;
its verified package was extracted locally instead, avoiding an administrator
installation. Private model settings and existing workspace data are preserved.

To reproduce font setup after cloning:

```text
run.bat fonts download
run.bat check
run.bat ui
```

## Practical limits

This is model-assisted reconstruction, not recovery of the original source
document. Exact typography and layout still depend on the analysis and available
font families. Unmatched illustrations require manual motif artwork, and
photographic elements stay raster images. The included 11 motifs are a starter
library, not a replacement for an arbitrary design catalog.

The real-model verification used a synthetic invitation. No customer catalog or
large batch was supplied for end-to-end fidelity testing. Etsy access and live
contributor delivery require the owner's corresponding credentials and were not
validated against external accounts in this review.
